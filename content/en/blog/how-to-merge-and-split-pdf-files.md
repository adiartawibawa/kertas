Your employment contract comes as three separate PDFs, the main document, an appendix, and a power of attorney, but the client wants it sent as a single file. Or the opposite: an 80-page annual report sits in one PDF, and your manager only needs chapter 3 for tomorrow's meeting. These two needs run in opposite directions, but both come up often, and neither requires paid PDF software.

## When You Need to Merge PDFs

**Documents that are administratively separate but should form one package.** A contract and its appendix, a proposal and a supporting portfolio, an invoice and its proof of payment. These often get created or received as separate files, but for sending or archiving, a single file is far more practical.

**Scan results split one page at a time.** Some scanners output one PDF per page instead of one file for the whole document. Twenty pages becomes twenty files, clearly needing a merge before anyone reads or sends it.

**Combined reports from several sources.** Each department sends its monthly report as a separate PDF, and you need to assemble them into one combined report for a management presentation.

### How to Merge PDFs

[PDF Merge](/office-tools/pdf/pdf-merge) handles this in a few simple steps:

1. **Upload all the PDF files you want to merge.** Several files at once work fine.
2. **Arrange the order.** The first file you upload becomes the first section of the merged result, rearrange if the order isn't right yet.
3. **Download the merged file.** One complete PDF, containing every page from the original files in sequence.

## When You Need to Split a PDF

**You only need part of it.** A thick report, but only a specific chapter matters right now. Rather than send the whole file and make the recipient scroll through it themselves, split off just the relevant part.

**Upload size limits.** Some systems cap the file size you can upload. A large PDF needs splitting into smaller pieces to fit.

**Separating documents that got merged by accident.** Scan results sometimes lump several different documents into one long PDF. Splitting by page range separates those documents back out.

### How to Split a PDF

[PDF Split](/office-tools/pdf/pdf-split) runs the opposite process:

1. **Upload the PDF you want to split.**
2. **Set the page ranges.** Choose which pages go into each piece, say pages 1-10 as the first file, 11-20 as the second.
3. **Download each piece.** Every page range becomes its own PDF file, ready to send or archive separately.

## What Stays the Same During Merge or Split

Unlike converting CSV to Excel, which loses some data along the way, merging or splitting a PDF **doesn't touch the page content at all**. Text, images, formatting, everything stays exactly as it was, because the process only rearranges existing pages rather than reading and rewriting their content. A merged or split file looks page-for-page identical to the source.

## Things Worth Watching For

**File order during a merge.** The final result follows upload order, so check it before downloading, especially with several files involved.

**Page numbers printed inside the document.** If the original PDF has page numbers printed on each page (not the PDF's own internal page count), merging several files doesn't automatically renumber them. A merged document can end up with numbering that jumps or repeats, because that number is part of the page content itself, not metadata that gets updated automatically.

**Scanned PDFs are images, not text.** If your PDF comes from a scan rather than a digital document, its content is actually an image, not selectable or searchable text. Merging and splitting still work fine for this kind of PDF, but if you later need to extract the text, that's a separate process called OCR.

## About Privacy

Documents you process, whether merged or split, never get sent to any server. The entire process runs in your own browser, which makes it fine to use even when the document holds contract details or other sensitive information.
