Anda menyiapkan lamaran kerja, dan formulir online menolak PDF Anda karena melewati batas ukuran. Atau email gagal terkirim karena lampirannya terlalu besar. Anda bisa mengecilkan ukuran file PDF tanpa mengurangi kualitas teks maupun gambar, dan prosesnya berjalan di browser tanpa unggahan.

## Kenapa Ukuran PDF Bisa Besar

Empat hal ini paling sering membuat PDF membengkak:

- **Gambar beresolusi tinggi.** Foto dan halaman hasil scan memakan ruang paling banyak.
- **Font tertanam.** Setiap font yang dipakai dokumen ikut tersimpan di dalam file.
- **Struktur dan metadata.** File menyimpan data internal dan keterangan dokumen yang tidak tampil di halaman.
- **Jumlah halaman.** Dokumen panjang lebih besar dari dokumen pendek.

## Kecilkan PDF dengan PDF Compress

[PDF Compress](/office-tools/pdf/pdf-compress) di Kertaas memadatkan struktur internal PDF untuk memperkecil ukuran file. Alat ini juga menghapus metadata, dan tidak menyentuh kualitas gambar atau teks.

1. Buka [PDF Compress](/office-tools/pdf/pdf-compress).
2. Pilih file PDF atau seret ke halaman.
3. Klik **Compress PDF**.
4. Bandingkan ukuran sebelum dan sesudah, lalu unduh hasilnya kalau Anda puas.

Alat ini menampilkan ukuran sebelum dan sesudah, lengkap dengan persentase yang berhasil dihemat. Browser memproses file di perangkat Anda, jadi dokumen seperti kontrak atau slip gaji tidak terkirim ke server.

## Seberapa Kecil Hasilnya

Hasilnya bergantung pada isi PDF. PDF Compress memadatkan struktur file, bukan menurunkan resolusi gambar.

| Jenis PDF                                          | Hasil yang bisa Anda harapkan                                |
| -------------------------------------------------- | ------------------------------------------------------------ |
| Dokumen berbasis teks                              | Ukuran bisa turun terasa                                     |
| PDF penuh gambar beresolusi tinggi atau hasil scan | Penghematan terbatas                                         |
| PDF hasil ekspor aplikasi modern                   | Ukuran mungkin hampir sama, karena strukturnya sudah efisien |

Kalau hasilnya hanya turun sedikit, file Anda sudah padat, atau gambarnya yang menentukan ukuran. Langkah berikutnya membantu untuk kasus itu.

## Kalau Ukuran Masih Terlalu Besar

Semua cara di bawah mengurangi isi file atau kualitas gambar, jadi pertimbangkan hasilnya sebelum memakainya.

**Ambil halaman yang dibutuhkan saja.** Pakai [Extract Pages](/office-tools/pdf/pdf-extract-pages) untuk memotong dokumen tebal menjadi beberapa halaman penting. Lampiran berisi tiga halaman jauh lebih kecil dari laporan seratus halaman.

**Pecah jadi beberapa file.** [PDF Split](/office-tools/pdf/pdf-split) membagi PDF menjadi beberapa bagian. Kirim bagian-bagian itu dalam email terpisah atau unggah satu per satu.

**Ekspor ulang dengan kualitas gambar lebih rendah.** Kalau Anda punya file sumbernya, simpan ulang sebagai PDF dengan opsi ukuran minimum. Di Microsoft Word, pilih **File**, **Save As**, format PDF, lalu atur **Optimize for** ke **Minimum size**.

**Scan ulang dengan resolusi lebih rendah.** Halaman hasil scan beresolusi tinggi membuat file besar. Untuk dokumen yang dibaca di layar, resolusi 150 sampai 200 dpi biasanya cukup terbaca.

**Pakai Preview di Mac.** Buka PDF di Preview, pilih **File**, **Export**, lalu pilih **Quartz Filter** bernama **Reduce File Size**. Kualitas gambar turun, jadi cek hasilnya sebelum mengirim.

## Urutan yang Disarankan

Kalau Anda menggabungkan beberapa PDF lewat [PDF Merge](/office-tools/pdf/pdf-merge), kompres file gabungannya sekali saja di akhir. Dengan begitu Anda tidak mengompres file berulang kali.

## Periksa Hasil Sebelum Mengirim

1. **Ukuran.** Pastikan ukuran akhir berada di bawah batas penerima.
2. **Halaman penting.** Buka halaman yang berisi gambar, tanda tangan, atau tabel, dan pastikan semuanya terbaca.
3. **File asli.** Simpan file asli di tempat terpisah. Metadata di file asli hilang pada hasil kompresi, dan Anda mungkin butuh versi lengkapnya nanti.

## Pertanyaan Umum

### Apakah kualitas PDF turun setelah dikompres?

Tidak. PDF Compress hanya memadatkan struktur file dan menghapus metadata. Resolusi gambar dan kualitas teks tetap sama.

### Kenapa ukuran file hampir tidak berubah?

PDF Anda mungkin sudah efisien, misalnya hasil ekspor langsung dari aplikasi modern. Atau gambar beresolusi tinggi mendominasi ukuran file, dan alat ini tidak mengecilkan gambar.

### Seberapa besar PDF bisa mengecil?

Tergantung isinya. PDF berbasis teks bisa turun terasa, sedangkan PDF penuh gambar turun lebih sedikit.

### Apakah file saya terunggah saat memakai PDF Compress?

Tidak. Kompresi berjalan di browser Anda, dan dokumen tidak terkirim ke server mana pun.
