Kontrak kerja Anda terdiri dari tiga file PDF terpisah, dokumen utama, lampiran, dan surat kuasa, padahal klien minta dikirim sebagai satu file saja. Atau sebaliknya, satu PDF laporan tahunan setebal 80 halaman, tapi atasan cuma butuh bab 3 saja untuk rapat besok. Dua kebutuhan ini kebalikan satu sama lain, tapi sama-sama sering muncul, dan sama-sama tidak butuh aplikasi PDF berbayar.

## Kapan Anda Perlu Menggabung PDF

**Dokumen yang terpisah secara administratif tapi seharusnya satu kesatuan.** Kontrak dan lampirannya, proposal dan portofolio pendukung, invoice dan bukti pembayaran. Semua ini sering dibuat atau diterima sebagai file terpisah, padahal untuk dikirim atau diarsipkan, satu file jauh lebih praktis.

**Hasil scan yang terpecah per halaman.** Scanner tertentu menghasilkan satu file PDF per halaman, bukan satu file untuk seluruh dokumen. Dua puluh halaman jadi dua puluh file, jelas perlu digabung sebelum dibaca atau dikirim.

**Gabungan laporan dari beberapa sumber.** Tiap divisi kirim laporan bulanan sebagai PDF terpisah, lalu Anda perlu menyusunnya jadi satu laporan gabungan untuk presentasi ke manajemen.

### Cara Menggabung PDF

[PDF Merge](/office-tools/pdf/pdf-merge) menyusun ini dalam beberapa langkah sederhana:

1. **Upload semua file PDF yang mau digabung.** Bisa langsung beberapa file sekaligus.
2. **Atur urutannya.** File pertama yang Anda upload jadi bagian pertama di hasil gabungan, susun ulang kalau urutannya belum sesuai.
3. **Download hasil gabungan.** Satu file PDF utuh, berisi semua halaman dari file asli secara berurutan.

## Kapan Anda Perlu Memecah PDF

**Cuma butuh sebagian halaman.** Laporan tebal, tapi yang relevan cuma bab tertentu. Daripada kirim seluruh file dan minta penerima scroll sendiri, pecah dulu jadi bagian yang relevan saja.

**Batas ukuran upload.** Beberapa sistem membatasi ukuran file yang bisa diupload. PDF besar perlu dipecah jadi beberapa bagian lebih kecil supaya muat.

**Memisahkan dokumen yang tergabung tidak sengaja.** Hasil scan kadang menyatukan beberapa dokumen berbeda jadi satu file PDF panjang. Memecahnya per rentang halaman memisahkan dokumen-dokumen itu kembali.

### Cara Memecah PDF

[PDF Split](/office-tools/pdf/pdf-split) bekerja berlawanan arah dari proses di atas:

1. **Upload file PDF yang mau dipecah.**
2. **Tentukan rentang halaman.** Pilih halaman mana saja yang masuk ke tiap bagian, misalnya halaman 1-10 jadi file pertama, 11-20 jadi file kedua.
3. **Download tiap bagian.** Setiap rentang halaman jadi file PDF terpisah, siap dikirim atau diarsipkan sendiri-sendiri.

## Yang Tidak Berubah Saat Digabung atau Dipecah

Berbeda dari konversi CSV ke Excel yang kehilangan sebagian data, menggabung atau memecah PDF **tidak mengubah isi halaman sama sekali**. Teks, gambar, formatting, semuanya tetap persis seperti aslinya, karena prosesnya cuma menyusun ulang halaman yang ada, bukan membaca ulang dan menulis ulang kontennya. File hasil merge atau split akan terlihat identik halaman demi halaman dengan file sumbernya.

## Hal yang Perlu Diperhatikan

**Urutan file saat merge.** Hasil akhir mengikuti urutan upload, jadi cek dulu urutannya sebelum download, terutama kalau filenya banyak.

**Penomoran halaman di dalam dokumen.** Kalau PDF asli punya nomor halaman tercetak di tiap lembar (bukan nomor halaman PDF itu sendiri), menggabung beberapa file tidak otomatis menyusun ulang nomor itu. Dokumen gabungan bisa punya penomoran yang meloncat atau berulang, karena nomor itu memang bagian dari konten halaman, bukan metadata yang bisa diubah otomatis.

**File PDF hasil scan gambar, bukan teks.** Kalau PDF Anda hasil scan (bukan dibuat langsung dari dokumen digital), isinya sebenarnya gambar, bukan teks yang bisa diseleksi atau dicari. Merge dan split tetap berfungsi normal untuk jenis PDF ini, tapi kalau Anda nanti perlu mengambil teksnya, itu proses terpisah yang disebut OCR.

## Soal Privasi

Dokumen yang Anda proses, baik digabung maupun dipecah, tidak pernah dikirim ke server mana pun. Seluruh proses berjalan di browser Anda sendiri, cocok dipakai meski dokumennya berisi data kontrak atau informasi yang sifatnya rahasia.
